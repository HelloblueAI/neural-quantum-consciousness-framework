# Support

Thanks for using and contributing to BleuJS Reasoning Lab.

## Questions and help

| Need | Where |
|------|--------|
| Bug report or feature request | [GitHub Issues](https://github.com/HelloblueAI/bleujs-reasoning-lab/issues) (use a template) |
| Setup, PR process, what we accept | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Starter tasks | [docs/GOOD_FIRST_ISSUES.md](docs/GOOD_FIRST_ISSUES.md) |
| Design discussion | [GitHub Discussions](https://github.com/HelloblueAI/bleujs-reasoning-lab/discussions) |
| Security vulnerability | [SECURITY.md](SECURITY.md) — private report only |

## Live demo

- Dashboard: [agi.bleujs.org](https://agi.bleujs.org)

Production deploy and Cloudflare secrets are **maintainer-only**. You do not need them to run evals, unit tests, or most local Worker work (see CONTRIBUTING).

## Response expectations

This is a small research lab. Best-effort replies on issues and discussions; security reports aim for acknowledgment within **72 hours** (see SECURITY.md).
